# Front-End Pages of BedaanWaves

## Front-End Pages List (12 Pages)

### 1. **Home Page** (`page.tsx`)
- **Path**: `/`
- **Description**: Landing page with overview of BedaanWaves capabilities
- **Features**: Introduction to the 4 pillars of the platform, TarotCard components for each pillar
- **Data**: Static content, no API calls

### 2. **Login Page** (`login/page.tsx`)
- **Path**: `/login`
- **Description**: Authentication interface with email/password login
- **Features**: 
  - Form validation
  - Show/hide password toggle
  - Remember me checkbox
  - Forgot password link
- **API**: `POST /auth/login`

### 3. **Register Page** (`register/page.tsx`)
- **Path**: `/register`
- **Description**: User registration interface
- **Features**:
  - Form validation (password min 8 chars, confirmation match)
  - Show/hide password toggle
  - Link to login page
- **API**: `POST /auth/register`

### 4. **Dashboard Page** (`dashboard/page.tsx`)
- **Path**: `/dashboard`
- **Description**: Main dashboard with market overview
- **Features**:
  - Market statistics (index, volume, gainers/losers)
  - Top movers table
  - Watchlist display
  - ML signals list
  - Latest news
  - Live data indicator
- **API**: `fetchDashboardData()` → `/market/tse-dashboard`, `/market/market-overview`, `/watchlists`, `/market/latest-prices`, `/analysis/signals-summary`, `/news/market`

### 5. **Stocks List Page** (`stocks/page.tsx`)
- **Path**: `/stocks`
- **Description**: Complete list of tradeable symbols with prices
- **Features**:
  - Market filtering (ALL, TSE, OTC, CRYPTO)
  - Search by symbol/name
  - Real-time price display with change badges
  - Links to detail pages
- **API**: `GET /market/symbols`, `GET /market/latest-prices`

### 6. **Stock Detail Page** (`stocks/[symbol]/page.tsx`)
- **Path**: `/stocks/[symbol]`
- **Description**: Detailed view for individual assets
- **Features**:
  - OHLCV candlestick chart with time range selector (1M/3M/All)
  - Real-time price and derived statistics
  - Market/sector info
  - Volume analysis
- **API**: `GET /market/price-history`, `GET /market/symbols` (for asset info), `GET /market/latest-prices`

### 7. **Analysis Page** (`analysis/page.tsx`)
- **Path**: `/analysis`
- **Description**: Multi-tab analysis interface
- **Features**:
  - 4 tabs: Technical, Fundamental, 6D Scoring, Sentiment
  - Signal analysis from ML models
  - Top performers display
  - Placeholder panels for detailed analysis
- **API**: `GET /analysis/signals-summary`, `GET /analysis/top-performers`, `GET /market/symbols`, `GET /analysis/signals/[symbol]`

### 8. **Portfolio Page** (`portfolio/page.tsx`)
- **Path**: `/portfolio`
- **Description**: Personal portfolio management
- **Features**:
  - Portfolio holdings with real-time prices
  - Portfolio statistics (total value, P&L, return %)
  - Performance chart placeholder
  - Asset allocation placeholder
- **API**: `GET /portfolios/holdings`, `GET /market/latest-prices`

### 9. **Settings Page** (`settings/page.tsx`)
- **Path**: `/settings`
- **Description**: System-wide configuration
- **Features**:
  - User profile display
  - Theme switching (Light/Dark)
  - Language selection (FA/EN)
  - Notification preferences (Email, Push, SMS, Telegram)
  - Quick actions grid
  - System info display

### 10. **Settings Profile Page** (`settings/profile/page.tsx`)
- **Path**: `/settings/profile`
- **Description**: User profile and security settings
- **Features**:
  - Profile info display
  - Account information
  - Password change functionality
  - Show/hide password toggles
- **API**: (Future) `GET /preferences`, `PUT /preferences`

### 11. **News Page** (`news/page.tsx`)
- **Path**: `/news`
- **Description**: Market news aggregation
- **Features**:
  - Source filtering
  - News listing with timestamps
  - Trending topics display (placeholder)
- **API**: `GET /news/market`

### 12. **Alerts Page** (`alerts/page.tsx`)
- **Path**: `/alerts`
- **Description**: System alerts and notifications management
- **Features**:
  - Alert type filtering (All, BUY, SELL, HOLD)
  - Active alerts from ML signals
  - Watchlist price alerts
  - Alert history from notifications
  - Alert statistics
- **API**: `GET /analysis/signals-summary`, `GET /watchlists`, `GET /market/latest-prices`, `GET /notifications`
