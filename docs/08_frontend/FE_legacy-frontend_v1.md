# BedaanWaves Frontend Documentation

## Overview
BedaanWaves frontend built with Next.js for portfolio analysis and market data visualization.

## Display Requirements

### Color Scheme
- Primary: #1E3A5F (Dark Blue)
- Secondary: #0D9488 (Teal)
- Accent: #F59E0B (Amber)

### Data Visualization
- Interactive charts using Plotly.js
- Real-time market data streaming
- Multi-market candlestick views

## Components
1. Dashboard
2. Portfolio Analyzer
3. News Feed
4. Market Screener
5. Technical Analysis
