# بررسی کلی پروژه Bedaan6D

## هدف اصلی پروژه

پروژه Bedaan6D یک پلتفرم تحلیل هوشمند بازار بورس تهران است که با استفاده از مدل‌های یادگیری ماشین و تحلیل ۶ بعدی، به سرمایه‌گذاران کمک می‌کند تصمیمات بهتری اتخاذ کنند. این پروژه امکان تحلیل جامع سهام، شاخص‌های بازار، طلا و ارز را فراهم می‌کند.

## قابلیت‌های کلیدی

### ۱. تحلیل ۶ بعدی سهام
- تحلیل بنیادی، تکنیکال، روانشناسی بازار، نقدینگی، ریسک و بازده
- محاسبه امتیاز هوشمند برای هر سهم
- شناسایی سهام برتر و پرریسک

### ۲. داده‌های زنده بازار
- اتصال به API بورس تهران برای دریافت داده‌های واقعی
- نمایش شاخص‌های اصلی بازار
- قیمت طلا و ارز به صورت بلادرنگ

### ۳. داشبورد تعاملی
- نمودارهای عنکبوتی برای نمایش امتیاز ۶ بعدی
- جدول‌های رتبه‌بندی سهام و صنایع
- تحلیل جزئیات هر سهم

### ۴. سیستم پیش‌بینی
- مدل رگرسیون خطی برای پیش‌بینی روند بازار
- تحلیل آماری داده‌های تاریخی
- ارائه سیگنال‌های خرید و فروش

## فناوری‌ها و ابزارهای استفاده شده

### فرانت‌اند
- **Next.js 16.2.9**: فریم‌ورک React با App Router و Turbopack
- **TypeScript**: برای توسعه نوع‌ایمن
- **React 19**: کتابخانه UI با Hooks جدید
- **Tailwind CSS 4**: فریم‌ورک CSS مدرن
- **shadcn/ui**: کتابخانه کامپوننت‌های UI
- **Recharts**: کتابخانه نمودارهای تعاملی

### بک‌اند
- **Node.js**: محیط اجرای سمت سرور
- **Next.js API Routes**: ساخت API داخلی
- **Prisma**: ORM برای پایگاه داده
- **SQLite**: پایگاه داده سبک برای توسعه
- **BRS API**: اتصال به داده‌های بورس تهران

### ابزارهای توسعه
- **Turbopack**: بیلدر سریع Next.js
- **ESLint**: تحلیل کد
- **npm**: مدیریت وابستگی‌ها
- **Git/GitHub**: کنترل نسخه

### زیرساخت و استقرار
- **Windows Batch File**: فایل اجرایی برای راه‌اندازی یک‌کلیکی
- **Next.js Standalone**: استقرار مستقل بدون نیاز به سرور Node.js
- **SQLite Embedded**: پایگاه داده توکار بدون نیاز به نصب جداگانه

## معماری کلی پروژه

### ساختار لایه‌ای
```
┌─────────────────────────────────────────┐
│           لایه رابط کاربری (Frontend)   │
│  (Next.js 16 + React 19 + Tailwind CSS) │
├─────────────────────────────────────────┤
│           لایه API و منطق کسب‌وکار      │
│  (Next.js API Routes + BRS Client)      │
├─────────────────────────────────────────┤
│           لایه داده و مدل‌ها             │
│  (Prisma ORM + SQLite + Mock Data)      │
├─────────────────────────────────────────┤
│           لایه منابع خارجی              │
│  (BRS API بورس تهران + Fallback Data)   │
└─────────────────────────────────────────┘
```

### الگوی طراحی
- **App Router**: ساختار مدرن Next.js برای مسیریابی
- **Client/Server Components**: جداسازی منطق سمت کلاینت و سرور
- **API Proxy**: واسط برای ارتباط با APIهای خارجی
- **Fallback Strategy**: استفاده از داده‌های جایگزین در صورت عدم دسترسی

## نحوه راه‌اندازی و اجرای اولیه

### پیش‌نیازها
- Node.js نسخه ۱۸ یا بالاتر
- npm یا bun
- مرورگر مدرن (Chrome, Firefox, Edge)

### مراحل نصب

#### ۱. کلون کردن مخزن
```bash
git clone https://github.com/Shakour-Data/Bedaan6D.git
cd Bedaan6D
```

#### ۲. نصب وابستگی‌ها
```bash
# نصب وابستگی‌های فرانت‌اند
npm install
```

#### ۳. تنظیم متغیرهای محیطی
```bash
# ایجاد فایل .env در ریشه پروژه
cp .env.example .env

# ویرایش فایل .env (اختیاری - تنظیمات پیش‌فرض کار می‌کند)
NEXTAUTH_URL="http://localhost:3005"
NEXTAUTH_SECRET="your-secret-key-here"
```

#### ۴. راه‌اندازی پایگاه داده
```bash
# ایجاد و پر کردن پایگاه داده SQLite
npm run db:push
```

#### ۵. اجرای برنامه
```bash
# راه‌اندازی dev server روی پورت 3005
npm run dev

# یا برای اجرای production
npm run build
npm run start:local
```

### استفاده از فایل اجرایی ویندوز (روش ساده)
1. فایل `start-bedaan6d.bat` را اجرا کنید
2. مرورگر به طور خودکار باز می‌شود: http://localhost:3005
3. برای توقف برنامه، ترمینال را ببندید یا Ctrl+C بزنید

### نکات مهم
- پروژه روی پورت 3005 اجرا می‌شود (برای جلوگیری از تداخل با پورت 3000)
- در صورت عدم دسترسی به API بورس تهران، از داده‌های جایگزین استفاده می‌شود
- برای تحلیل ML، به آدرس `/api/ml/predict` مراجعه کنید
